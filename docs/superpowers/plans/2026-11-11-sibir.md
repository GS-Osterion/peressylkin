# «Ссылка в Сибирь» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows-утилита, переносящая папки на другой диск с junction на старом месте, с контекстным меню, GUI и консольным режимом для агентов.

**Architecture:** Ядро (`Sibir.Core` — пространство имён внутри одного проекта) без UI: проверки, распознавание лаунчеров, копирование, перенос/откат/доследование, архив. Две тонкие оболочки — `Cli` и `Gui` — над ядром; `Shell` — регистрация в Проводнике и сбор мультивыбора. Всё, что трогает ОС (диски, реестр, лаунчеры), идёт через интерфейсы окружения, чтобы тесты подставляли фейки.

**Tech Stack:** C# (LangVersion latest), .NET Framework 4.8, WinForms, xUnit 2.x на net48, .NET SDK 10 для сборки, P/Invoke (DeviceIoControl, CopyFileEx, Restart Manager, AttachConsole), `System.Web.Script.Serialization.JavaScriptSerializer` для JSON (без NuGet-зависимостей в рантайме).

**Spec:** `docs/superpowers/specs/2026-11-11-sibir-design.md`

## Global Constraints

- Целевая платформа net48; в выходной папке — один `Sibir.exe` (плюс `stamp.ico`, `sibir.ico`); никаких сторонних DLL в рантайме.
- Установка и работа без прав администратора; только HKCU.
- Все тексты для людей — только в `src/Sibir/Strings.cs` (таблица §2 спеки, дословно).
- Коды причин (английские, стабильные): `already_exiled`, `in_siberia`, `case_open`, `target_is_source`, `capital`, `protected`, `same_drive`, `network_target`, `no_space`, `removable_target`, `launcher`, `store_app`, `registered_app`, `nested`, `target_exists`, `locked`, `needs_admin`, `copy_failed`, `verify_failed`, `not_exiled`, `no_destination`, `bad_args`.
- Коды выхода: 0 успех · 1 ошибка аргументов · 2 отказ проверок · 3 занято процессом · 4 сбой с откатом · 5 нужны права администратора · 6 есть незакрытые дела.
- Суффиксы временных папок: `.~пересылка`, `.~этап`, `.~возвращение`.
- Архив: `%LOCALAPPDATA%\Sibir\archive.jsonl`; статусы `in_transit`, `exiled`, `amnestied`, `rehabilitating`, `rehabilitated`.
- Копирование: `COPY_FILE_NO_BUFFERING` для файлов > 256 МБ; мелкие файлы — 4 потока; запас места 5%.
- Оригинал не изменяется до успешного досмотра (шаг 3).
- Комментарии в коде и сообщения коммитов — по-английски; каждый коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Папка-источник меняется во время копирования** (игра пишет сейв, но файл не держит) — досмотр видит расхождение → амнистия, оригинал цел. Тест: `Mover_FileChangedBetweenCopyAndVerify_Amnesty` (Task 7).
2. **Целевой диск заполнился посреди копирования** — откат, оригинал цел, `~пересылка` удалена. Тест: `Mover_CopyThrowsDiskFull_Amnesty` (Task 7).
3. **Пути-обманки**: `c:\x\` vs `C:\X`, завершающий слэш, `subst`-диск на тот же том, относительный путь — нормализация и сравнение томов, `same_drive` срабатывает. Тест: `Checks_SameVolumeViaDifferentSpelling_Refused` (Task 4).
4. **Внутри папки junction, ведущий на другой диск** — копируется ссылка, а не гигабайты содержимого; при реабилитации ссылка восстанавливается. Тест: `Copier_NestedJunction_CopiedAsLink` (Task 6).
5. **Реабилитация, когда место прописки занято** (на старом пути уже не junction, а настоящая папка — пользователь или программа пересоздали её) — отказ `target_exists`, ничего не удаляется. Тест: `Mover_RehabWhenSourceReplacedByRealFolder_Refused` (Task 7).
